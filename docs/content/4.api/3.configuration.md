## Configuration

`load_config()` reads the TOML config and produces a `BwsshConfig` object
with daemon, Bitwarden, auth, and SSH sections.

## Keys

Key utilities support Ed25519, RSA, and ECDSA keys:

- `load_private_key()` parses SSH private key data.
- `get_public_key_blob()` extracts the OpenSSH public key blob.
- `compute_fingerprint()` returns a SHA256 fingerprint.

`KeyRegistry` stores identities and private keys in memory.
