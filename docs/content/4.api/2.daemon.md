## AgentServer

`AgentServer` handles SSH agent protocol connections, key registry access,
and polkit authorization.

Key methods:

- `serve()` starts the Unix socket server.
- `shutdown()` stops the server.
- `lock()` clears loaded keys.

## ControlServer and ControlClient

The control socket provides a JSON-RPC style API for daemon management.

- `ControlServer` exposes `status`, `list_keys`, `lock`, `unlock`, `sync`,
  and `reload_config`.
- `ControlClient` sends commands over the control socket.
