## bwssh

`bwssh` is the primary CLI for user workflows.

Commands include `status`, `start`, `stop`, `install`, `unlock`, `lock`,
`sync`, and `keys`.

## bwssh-agentd

`bwssh-agentd` runs the daemon process. The recommended usage is via
systemd user services. For debugging, use `--foreground`.
