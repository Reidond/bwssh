## polkit authorization

bwssh uses polkit to authorize signing operations. Each request includes
process metadata and key identifiers to help users make safe approvals.

Install the policy file:

```bash
bwssh install --polkit | sudo tee /etc/polkit-1/actions/io.github.reidond.bwssh.policy
```

## Approval modes

- `always`: prompt for every sign request.
- `per_connection`: authorize once per agent connection.
- `ttl`: authorize per key fingerprint + executable for a time window.

## Forwarding behavior

Forwarded agent requests are a common attack surface. Set
`deny_forwarded_by_default = true` to block forwarded requests unless you
explicitly allow them.
