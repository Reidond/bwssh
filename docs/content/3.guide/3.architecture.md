## Components

- **Agent socket**: implements the SSH agent protocol for OpenSSH tools.
- **Control socket**: JSON-RPC style API for status, sync, lock, and unlock.
- **Bitwarden provider**: fetches key material using the Bitwarden CLI.
- **polkit authorizer**: gates signing requests.

## Flow

1. The client connects to the agent socket.
2. The daemon identifies the client process.
3. For sign requests, polkit authorization is evaluated.
4. If approved, the daemon signs data using the selected key.
