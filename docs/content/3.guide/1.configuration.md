---
title: "Configuration"
description: "Configure sockets, Bitwarden, auth, and SSH behavior."
---

Config file location:

```
${XDG_CONFIG_HOME:-~/.config}/bwssh/config.toml
```

## Example

```toml
[daemon]
agent_socket = "agent.sock"
control_socket = "control.sock"
log_level = "INFO"

[bitwarden]
bw_path = "bw"
mode = "explicit"
item_ids = []

[auth]
approval_mode = "per_connection"
approval_ttl_seconds = 300
deny_forwarded_by_default = true

[ssh]
allow_ed25519 = true
allow_ecdsa = true
allow_rsa = true
prefer_rsa_sha2 = true
```

## Environment overrides

- `BWSSH_RUNTIME_DIR` overrides the daemon runtime directory.
- `BWSSH_LOG_LEVEL` overrides the log level.
