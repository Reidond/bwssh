---
title: "Commands"
description: "Reference for bwssh CLI commands."
---

## Show daemon status

```bash
bwssh status
```

## Start the daemon

```bash
bwssh start
```

## Stop the daemon

```bash
bwssh stop
```

## Install systemd or polkit assets

```bash
bwssh install --user-systemd
bwssh install --polkit
```

## Unlock Bitwarden and load keys

```bash
bwssh unlock
```

## Lock the agent

```bash
bwssh lock
```

## Sync keys from Bitwarden

```bash
bwssh sync
```

## List loaded keys

```bash
bwssh keys
```
