title: "Commands"
description: "Reference for bwssh CLI commands."
---

## Show daemon status

```bash
bwssh status
```

## Start the daemon

```bash
bwssh start
```

## Stop the daemon

```bash
bwssh stop
```

## Install service integration

```bash
# Linux: install systemd user units
bwssh install --user-systemd

# macOS: install launchd user agent
bwssh install --launchd

# Linux: print polkit policy to stdout
bwssh install --polkit
```

## Unlock Bitwarden and load keys

```bash
bwssh unlock
```

## Lock the agent

```bash
bwssh lock
```

## Sync keys from Bitwarden

```bash
bwssh sync
```

## List loaded keys

```bash
bwssh keys
```
