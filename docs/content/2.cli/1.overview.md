title: "Overview"
description: "CLI entry points and high-level behavior."
---

bwssh exposes two entry points:

- `bwssh` for user commands.
- `bwssh-agentd` for the daemon process.

## Help and version

```bash
bwssh --help
bwssh --version
```

## Sockets

- Agent socket: `${XDG_RUNTIME_DIR}/bwssh/agent.sock`
- Control socket: `${XDG_RUNTIME_DIR}/bwssh/control.sock`

## Daemon modes

The daemon is intended to run under systemd user services. For debugging,
you can run it in the foreground:

```bash
bwssh-agentd --foreground
```
